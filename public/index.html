Import formats Loading upload limits…

CSV, TSV, delimited TXT: the first row provides column names. Quoted fields and multiline values are supported.

Excel XLSX: each nonempty worksheet becomes a table. Formulas use cached results; formulas and macros are never executed.

JSON: use normalized model metadata, an array of flat records, or a rows/data array. JSONL / NDJSON: one flat record per line. XML: one root with repeated flat record children.

Power BI BIM: imports model tables, columns, measures, and relationships. Tabular files provide inferred columns and types, with row counts. They do not supply DAX measures or model relationships.

Select Replace model to start a new model or Add tables to extend the current one. Duplicate table names get a suffix; relationships from metadata files follow those renamed tables. An import failure keeps the current model.

Legacy XLS, PBIX, PBIP, TMDL, PDF, images, and other formats are not supported. Save spreadsheets as XLSX/CSV, or export Power BI metadata as BIM/JSON.

Generated model JSON is limited to 2 MB. Uploads are parsed in memory, so row and workbook limits also apply.

The result is editable model metadata, not a runnable Power BI dataset. Data rows are processed in this workspace and are not saved.

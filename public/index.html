Data files

CSV / TSV / TXT: a header row and comma, tab, semicolon, or pipe separators. Quoted fields and multiline values are supported.

Excel XLSX: sheets become tables. All rows are counted; types use the first 5,000 data rows. Review detected headers and sampling notes. Formulas use cached results and are never executed.

JSON / JSONL / NDJSON / XML: flat record arrays, one object per line, or repeated flat XML records. JSON also accepts a rows or data wrapper.

Model metadata

BIM / JSON: tables, columns, DAX measures, and relationships. Data files infer columns and types; add measures and relationships separately.

Replace the model or add tables. Duplicate names receive a suffix; relationships follow the renamed tables. Review DAX after renaming. Failed batches keep the current model.

Generated model JSON is limited to 2 MB. CSV/JSON/XML: up to 50,000 rows. Excel: up to 200 MB expanded, with merged ranges excluded from data counts. Up to 512 columns per table.

PBIX, PBIP, TMDL, XLS, PDF, and images need conversion. Data rows are processed in memory and are not saved. This workspace produces metadata and guidance, not a runnable dataset.
